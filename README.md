# Verix - AI-powered identity verification

> React · TypeScript · Vite

[![React](https://img.shields.io/badge/React-TypeScript-blue?style=flat-square)](https://react.dev)
[![Vite](https://img.shields.io/badge/Build-Vite-646CFF?style=flat-square)](https://vitejs.dev)
[![SCSS](https://img.shields.io/badge/Styles-SCSS%20%2B%20BEM-CC6699?style=flat-square)](https://sass-lang.com)

Frontend landing page for an AI-powered identity verification platform. Built as a product-focused SaaS landing with emphasis on UI quality, accessibility, and scalable frontend architecture.

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React + TypeScript |
| Build tool | Vite |
| Styles | SCSS with ITCSS and BEM |
| Theming | CSS variables (design tokens) |
| Layout | Mobile-first responsive system |
| Typography | Fluid `clamp()` |

---

## Project Structure

```
src/
├── app/        # Application entry and providers
├── pages/      # Page-level components
├── widgets/    # Independent UI sections (hero, features, faq, cta…)
├── shared/     # Reusable UI components and utilities
└── styles/     # Design system - tokens, mixins, base styles
```

---

## Design System

- **Tokens** - colors, typography, spacing, layout
- **Spacing** - semantic system based on CSS variables
- **Typography** - fluid scaling with `clamp()`
- **Breakpoints** - mobile-first
- **Mixins** - reusable SCSS helpers
